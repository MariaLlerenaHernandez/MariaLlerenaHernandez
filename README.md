## Sobre mí

Construyo aplicaciones completas: diseño la base de datos, levanto la capa de
persistencia, expongo la API y la dejo corriendo detrás de un servidor web.
Me interesa especialmente lo que pasa **después** de escribir el código —
contenerizar, desplegar y que siga funcionando cuando lo usa alguien más.

Cada repositorio de este perfil nació de esa idea: terminar lo que se empieza.

**Sistema de facturación de escritorio**

Aplicación completa para gestionar clientes, productos, formas de pago y
facturas (cabecera y detalle), con inicio de sesión, reportes en JasperReports

fuera del control de versiones.

`Java 11` · `JavaFX` · `Hibernate / JPA` · `HikariCP` · `SQL Server` · `JasperReports` · `i18n` · `MVC`
